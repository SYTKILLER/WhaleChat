# 📦 迭代存档系统

## 目录结构

```
archive/
├── README.md              ← 本文件
├── CHANGELOG.md           ← 迭代更新记录
├── rollback.ps1           ← 回滚脚本 (PowerShell)
└── iterations/
    ├── iter_001/           ← 第 1 次迭代快照
    │   ├── REPORT.md       ←   迭代报告
    │   ├── src/            ←   源代码快照
    │   └── config/         ←   构建配置快照
    ├── iter_002/           ← 第 2 次迭代快照
    │   └── ...
    └── ...
```

## 规则

| 规则 | 说明 |
|------|------|
| **保留数量** | 仅保留最近 2 次迭代的完整文件快照 |
| **回滚方式** | 执行 `archive/rollback.ps1 <iter编号>` 即可回滚 |
| **记录要求** | 每次迭代必须在 `CHANGELOG.md` 中记录变更 |
| **快照内容** | 每次迭代保存 `entry/src/main/ets/`、资源文件、配置文件 |

## 新增迭代

在 AI 对话中执行以下步骤：
1. 完成本轮所有代码修改
2. 说 **"存档当前迭代"** → AI 将自动创建新快照
3. 旧快照 (超过 2 个) 将自动清理

## 回滚到历史版本

```powershell
# 在项目根目录执行
./archive/rollback.ps1 001    # 回滚到迭代 1
./archive/rollback.ps1 002    # 回滚到迭代 2
```

⚠️ 回滚会覆盖当前工作区文件，请确保当前修改已存档。
